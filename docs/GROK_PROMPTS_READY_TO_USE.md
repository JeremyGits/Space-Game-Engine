## 📋 WORKFLOW

### For Each Asset:

1. **Copy prompt** from above
2. **Paste into Grok Imagine**
3. **Set style and quality** as specified
4. **Generate** (may take a few moments)
5. **Review** the result
6. **Regenerate** if needed (try 2-3 variations)
7. **Download** at highest quality
8. **Save** to appropriate folder in `/public/ai-generated/`

### For Depth Maps:

1. **Generate original first**
2. **Then use depth map prompt**
3. **OR** use AI depth estimation tool (MiDaS, DepthAnything)
4. **Verify** darker = closer, lighter = further
5. **Ensure** same dimensions as original
6. **Save** with `-depth` suffix

---

## 💡 TIPS

### Getting Better Results:

1. **Be Specific:** More details = better results
2. **Iterate:** Generate 3-5 variations, pick best
3. **Consistent Style:** Use similar language for related assets
4. **Check Dimensions:** Verify original and depth match
5. **Test Early:** Try one asset through full pipeline before batch generating

### Common Issues:

**Problem:** Depth map not accurate
**Solution:** Use AI depth estimation tool or manually adjust in GIMP

**Problem:** Colors too dark/bright
**Solution:** Adjust in image editor or regenerate with lighting keywords

**Problem:** Perspective wrong
**Solution:** Add "first-person view" or "pilot perspective" to prompt

## ✅ QUALITY CHECKLIST

Before using generated images:

- [ ] Image is high resolution (min 1024x1024)
- [ ] Perspective is correct (first-person for cockpits)
- [ ] Lighting is clear and consistent
- [ ] All details are visible
- [ ] Depth map matches original dimensions
- [ ] Depth encoding is correct (darker = closer)
- [ ] File is saved to correct folder
- [ ] File is named correctly
- [ ] PNG format (lossless)
