🔬 Voxel Clustering & Gap Filling System

Status: ✅ COMPLETE - Revolutionary Technology

Overview

The Voxel Clustering System is a custom innovation that groups voxel nanites together and fills gaps between them to create solid, cohesive 3D objects from scattered point clouds.

💡 The Innovation

"Finding nearest neighbors with triangles/voxels to fill in gaps in groups, kind of like splatting but with triangles or voxels!"

This system makes scattered voxel nanites look like solid, real entities by:

  • Grouping nearby nanites into clusters
  • Detecting gaps between clusters
  • Filling small gaps with interpolated voxels
  • Filling large gaps with triangle meshes
  • Matching colors from surrounding nanites

Architecture

Core Components

  • VoxelClusterer - Main clustering coordinator
  • KMeansClustering - Partition-based clustering
  • DBSCANClustering - Density-based clustering
  • SpatialClustering - Proximity-based grouping
  • ColorClustering - Color similarity grouping
  • SimilarityMetrics - Distance calculations

Clustering Algorithms

1. K-Means Clustering

Best for: Uniform distribution of voxels

const clusterer = new KMeansClustering();
const result = await clusterer.cluster(voxels, {
  k: 10,              // Number of clusters
  maxIterations: 100,
  tolerance: 0.001
});

2. DBSCAN Clustering

Best for: Finding arbitrary shapes, handling noise

const clusterer = new DBSCANClustering();
const result = await clusterer.cluster(voxels, {
  eps: 2.0,          // Neighborhood radius
  minPts: 5          // Minimum points per cluster
});

3. Spatial Clustering

Best for: Fast proximity-based grouping

const clusterer = new SpatialClustering();
const result = await clusterer.cluster(voxels, {
  threshold: 5.0     // Maximum distance
});

4. Color Clustering

Best for: Preserving visual coherence

const clusterer = new ColorClustering();
const result = await clusterer.cluster(voxels, {
  colorThreshold: 0.1  // Color difference threshold
});

Gap Filling System

How It Works

  1. Detect Neighbors: Find clusters that are close to each other
  2. Measure Gaps: Calculate distance between cluster centers
  3. Fill Strategy:
    • Small gaps (< 2 units): Insert interpolated voxel
    • Large gaps (>= 2 units): Generate triangle mesh
  4. Color Matching: Interpolate colors from neighboring clusters

Gap Fill Types

Voxel Fill (Small Gaps)

interface VoxelGapFill {
  position: Vector3;        // Midpoint between clusters
  color: Color;             // Interpolated color
  type: 'voxel';
  neighborClusters: number[];
}

Triangle Fill (Large Gaps)

interface TriangleGapFill {
  position: Vector3;
  color: Color;
  type: 'triangle';
  triangleVertices: [Vector3, Vector3, Vector3];
  neighborClusters: number[];
}

Usage Example

import { VoxelClusterer, ClusteringAlgorithm } from './voxel/clustering';

// Create clusterer
const clusterer = new VoxelClusterer({
  algorithm: ClusteringAlgorithm.SPATIAL,
  maxClusterSize: 1000,
  minClusterSize: 10,
  enableGapFilling: true,
  gapThreshold: 2.0
});

// Perform clustering
const result = await clusterer.cluster(voxels);

console.log(`Created ${result.clusters.length} clusters`);
console.log(`Filled ${result.gapFills.length} gaps`);

// Access clusters
for (const cluster of result.clusters) {
  console.log(`Cluster ${cluster.id}:`);
  console.log(`  Voxels: ${cluster.voxels.length}`);
  console.log(`  Center: ${cluster.center}`);
  console.log(`  Density: ${cluster.density}`);
  console.log(`  Neighbors: ${cluster.neighbors.length}`);
}

// Access gap fills
for (const gap of result.gapFills) {
  if (gap.type === 'voxel') {
    // Add voxel at gap position
    addVoxel(gap.position, gap.color);
  } else {
    // Generate triangle mesh
    addTriangle(gap.triangleVertices, gap.color);
  }
}

Similarity Metrics

Color Similarity

class ColorSimilarity {
  calculate(colorA: Color, colorB: Color): number {
    const dr = colorA.r - colorB.r;
    const dg = colorA.g - colorB.g;
    const db = colorA.b - colorB.b;
    const distance = Math.sqrt(dr*dr + dg*dg + db*db);
    return 1 - (distance / Math.sqrt(3));
  }
}

Spatial Proximity

class SpatialProximity {
  calculate(posA: Vector3, posB: Vector3, threshold: number): number {
    const distance = posA.distanceTo(posB);
    return Math.max(0, 1 - (distance / threshold));
  }
}

Weighted Similarity

class WeightedSimilarity {
  calculate(voxelA: Voxel, voxelB: Voxel): number {
    const colorSim = colorSimilarity.calculate(voxelA.color, voxelB.color);
    const spatialSim = spatialProximity.calculate(voxelA.pos, voxelB.pos);
    const materialSim = voxelA.material === voxelB.material ? 1 : 0;
    
    return (
      0.4 * colorSim +
      0.4 * spatialSim +
      0.2 * materialSim
    );
  }
}

Real-World Application

Making Hologram Look Solid

The clustering system is used in the Ultra Hologram Demo to make scattered nanites appear as a cohesive character:

// 1. Generate voxel nanites from image
const nanites = await imageToVoxelNanites('/trumptest.png');

// 2. Cluster nanites
const clusterer = new VoxelClusterer({
  algorithm: ClusteringAlgorithm.SPATIAL,
  enableGapFilling: true,
  gapThreshold: 0.5  // Tight packing
});

const result = await clusterer.cluster(nanites);

// 3. Render clusters + gap fills
renderClusters(result.clusters);
renderGapFills(result.gapFills);

// Result: Solid, cohesive hologram!

Advanced Features

Cluster Merging

Small clusters are automatically merged with nearest neighbors:

// Clusters with < minClusterSize voxels are merged
if (cluster.voxels.length < minClusterSize) {
  const nearest = findNearestCluster(cluster, otherClusters);
  mergeInto(cluster, nearest);
}

Cluster Splitting

Large clusters are split using octree partitioning:

// Clusters with > maxClusterSize voxels are split
if (cluster.voxels.length > maxClusterSize) {
  const subclusters = spatialSplit(cluster);
  clusters.push(...subclusters);
}

Neighbor Detection

Automatic neighbor relationship tracking:

// Two clusters are neighbors if:
distance <= (radiusA + radiusB) * 1.5

Configuration Options

interface ClusteringOptions {
  // Algorithm selection
  algorithm?: 'kmeans' | 'dbscan' | 'spatial' | 'color' | 'hybrid';
  
  // Cluster size limits
  maxClusterSize?: number;      // Default: 1000
  minClusterSize?: number;      // Default: 10
  
  // Gap filling
  enableGapFilling?: boolean;   // Default: true
  gapThreshold?: number;        // Default: 2.0
  
  // Similarity thresholds
  colorThreshold?: number;      // Default: 0.1
  spatialThreshold?: number;    // Default: 5.0
}

Performance Tips

✅ DO:

  • Use Spatial clustering for real-time applications
  • Enable gap filling for better visual quality
  • Adjust thresholds based on voxel density
  • Cache clustering results when possible

❌ DON'T:

  • Use K-Means for very large datasets (slow)
  • Set minClusterSize too low (creates noise)
  • Disable gap filling for hero assets
  • Re-cluster every frame (expensive)
