🎮 Input System

Unified input handling for keyboard, mouse, and gamepad

Overview

The Input System provides a unified interface for handling input from multiple devices (keyboard, mouse, gamepad) with support for:

  • ✅ Keyboard input with key bindings
  • ✅ Mouse input with pointer lock support
  • ✅ Gamepad/controller support (Gamepad API)
  • ✅ Action mapping (discrete inputs like jump, shoot)
  • ✅ Axis mapping (continuous inputs like movement)
  • ✅ Input recording and playback
  • ✅ Configurable sensitivity and dead zones

InputManager

The InputManager is the main entry point for the input system:

src/engine/input/InputManager.ts
class InputManager {
  private keyboard: KeyboardInput;
  private mouse: MouseInput;
  private gamepad: GamepadInput;
  private mapper: InputMapper;
  private state: InputState;
  
  constructor(config: InputConfig) {
    this.keyboard = new KeyboardInput();
    this.mouse = new MouseInput(config.mouseSensitivity);
    this.gamepad = new GamepadInput();
    this.mapper = new InputMapper();
    this.state = new InputState();
  }
  
  initialize(canvas: HTMLCanvasElement): void {
    this.keyboard.initialize();
    this.mouse.initialize(canvas);
    this.gamepad.initialize();
  }
  
  update(deltaTime: number): void {
    // Update all input devices
    this.keyboard.update(deltaTime);
    this.mouse.update(deltaTime);
    this.gamepad.update(deltaTime);
    
    // Update mapped inputs
    this.mapper.update(this.state);
  }
  
  // Get action value (0 or 1)
  getAction(name: string): number {
    return this.state.getAction(name);
  }
  
  // Get axis value (-1 to 1)
  getAxis(name: string): number {
    return this.state.getAxis(name);
  }
  
  dispose(): void {
    this.keyboard.dispose();
    this.mouse.dispose();
    this.gamepad.dispose();
  }
}

Basic Usage

// Create input manager
const inputManager = new InputManager({
  enableKeyboard: true,
  enableMouse: true,
  enableGamepad: true,
  mouseSensitivity: 0.5
});

// Initialize with canvas
const canvas = document.querySelector('canvas');
inputManager.initialize(canvas);

// In game loop
inputManager.update(deltaTime);

// Get input values
const moveForward = inputManager.getAxis('moveForward');
const jump = inputManager.getAction('jump');

Actions and Axes

Actions

Actions are discrete inputs (pressed/not pressed) like jump, shoot, interact:

// Define an action
inputManager.addAction({
  name: 'jump',
  bindings: [
    { device: 'keyboard', input: 'Space' },
    { device: 'gamepad', input: 'button_0' }  // A button
  ]
});

// Check if action is pressed
if (inputManager.getAction('jump') > 0.5) {
  player.jump();
}

Axes

Axes are continuous inputs (-1 to 1) like movement, steering:

// Define an axis
inputManager.addAxis({
  name: 'moveForward',
  positive: { device: 'keyboard', input: 'KeyW' },
  negative: { device: 'keyboard', input: 'KeyS' },
  deadzone: 0.1,
  sensitivity: 1.0,
  gravity: 10.0,  // How fast it returns to 0
  snap: true      // Snap to 0 when switching directions
});

// Get axis value
const moveForward = inputManager.getAxis('moveForward');
player.move(moveForward * speed * deltaTime);

Axis Parameters

  • deadzone - Ignore small values (prevents drift)
  • sensitivity - Multiplier for input value
  • gravity - Speed of return to neutral (0)
  • snap - Instantly snap to 0 when reversing direction

Gamepad Input

Gamepad Support

Full support for Xbox, PlayStation, and generic controllers via the Gamepad API:

src/engine/input/core/GamepadInput.ts
class GamepadInput {
  private gamepads: Map;
  private deadzone: number = 0.15;
  
  update(deltaTime: number): void {
    // Get connected gamepads
    const gamepads = navigator.getGamepads();
    
    for (let i = 0; i < gamepads.length; i++) {
      const gamepad = gamepads[i];
      if (gamepad) {
        this.updateGamepad(gamepad);
      }
    }
  }
  
  private updateGamepad(gamepad: Gamepad): void {
    // Update axes (analog sticks)
    for (let i = 0; i < gamepad.axes.length; i++) {
      let value = gamepad.axes[i];
      
      // Apply deadzone
      if (Math.abs(value) < this.deadzone) {
        value = 0;
      }
      
      this.state.setAxis(`gamepad_axis_${i}`, value);
    }
    
    // Update buttons
    for (let i = 0; i < gamepad.buttons.length; i++) {
      const button = gamepad.buttons[i];
      this.state.setButton(`gamepad_button_${i}`, button.value);
    }
  }
  
  vibrate(duration: number, intensity: number): void {
    const gamepad = this.getFirstGamepad();
    if (gamepad?.vibrationActuator) {
      gamepad.vibrationActuator.playEffect('dual-rumble', {
        duration,
        strongMagnitude: intensity,
        weakMagnitude: intensity * 0.5
      });
    }
  }
}

Input Mapping

InputMapper

Maps raw device inputs to game actions and axes:

src/engine/input/InputMapper.ts
class InputMapper {
  private actions: Map;
  private axes: Map;
  
  addAction(config: ActionConfig): void {
    const action = new InputAction(config.name, config.bindings);
    this.actions.set(config.name, action);
  }
  
  addAxis(config: AxisConfig): void {
    const axis = new InputAxis(config);
    this.axes.set(config.name, axis);
  }
  
  update(state: InputState): void {
    // Update all actions
    for (const action of this.actions.values()) {
      const value = this.evaluateAction(action);
      state.setAction(action.name, value);
    }
    
    // Update all axes
    for (const axis of this.axes.values()) {
      const value = this.evaluateAxis(axis);
      state.setAxis(axis.name, value);
    }
  }
  
  private evaluateAction(action: InputAction): number {
    for (const binding of action.bindings) {
      const value = this.getDeviceInput(binding);
      if (value > 0.5) return 1;
    }
    return 0;
  }
  
  private evaluateAxis(axis: InputAxis): number {
    let value = 0;
    
    // Check positive binding
    if (axis.positive) {
      value += this.getDeviceInput(axis.positive);
    }
    
    // Check negative binding
    if (axis.negative) {
      value -= this.getDeviceInput(axis.negative);
    }
    
    // Apply deadzone
    if (Math.abs(value) < axis.deadzone) {
      value = 0;
    }
    
    // Apply sensitivity
    value *= axis.sensitivity;
    
    // Clamp to -1 to 1
    return Math.max(-1, Math.min(1, value));
  }
}

  ]

function gameLoop(deltaTime) {
  // Update input
  inputManager.update(deltaTime);
  
  // Get input values
  const input = {
    moveForward: inputManager.getAxis('moveForward'),
    moveRight: inputManager.getAxis('moveRight'),
    lookX: inputManager.getAxis('lookX'),
    lookY: inputManager.getAxis('lookY'),
    jump: inputManager.getAction('jump') > 0.5,
    sprint: inputManager.getAction('sprint') > 0.5,
    crouch: inputManager.getAction('crouch') > 0.5
  };
  
  // Use input to control player
  player.move(input.moveForward, input.moveRight);
  player.look(input.lookX, input.lookY);
  
  if (input.jump) player.jump();
  if (input.sprint) player.setSprinting(true);
  if (input.crouch) player.setCrouching(true);
}

Input Recording

Record and playback input for replays, testing, or AI training:

src/engine/input/InputRecorder.ts
class InputRecorder {
  private recording: boolean = false;
  private playing: boolean = false;
  private frames: InputFrame[] = [];
  private currentFrame: number = 0;
  
  startRecording(): void {
    this.recording = true;
    this.frames = [];
  }
  
  stopRecording(): void {
    this.recording = false;
  }
  
  record(state: InputState): void {
    if (!this.recording) return;
    
    this.frames.push({
      timestamp: performance.now(),
      actions: state.getAllActions(),
      axes: state.getAllAxes()
    });
  }
  
  startPlayback(): void {
    this.playing = true;
    this.currentFrame = 0;
  }
  
  stopPlayback(): void {
    this.playing = false;
  }
  
  playback(state: InputState): void {
    if (!this.playing || this.currentFrame >= this.frames.length) {
      this.stopPlayback();
      return;
    }
    
    const frame = this.frames[this.currentFrame];
    state.setFromFrame(frame);
    this.currentFrame++;
  }
  
  save(): string {
    return JSON.stringify(this.frames);
  }
  
  load(data: string): void {
    this.frames = JSON.parse(data);
  }
}

Usage

const recorder = new InputRecorder();

// Start recording
recorder.startRecording();

// In game loop
recorder.record(inputManager.getState());

// Stop and save
recorder.stopRecording();
const recordingData = recorder.save();
localStorage.setItem('replay', recordingData);

// Later: Load and playback
const data = localStorage.getItem('replay');
recorder.load(data);
recorder.startPlayback();

// In game loop
recorder.playback(inputManager.getState());

Input Buffering

Buffer inputs for responsive controls:

class InputBuffer {
  private buffer: Map;
  private bufferTime: number = 0.1; // 100ms
  
  bufferAction(name: string): void {
    this.buffer.set(name, performance.now());
  }
  
  consumeAction(name: string): boolean {
    const time = this.buffer.get(name);
    if (!time) return false;
    
    const elapsed = (performance.now() - time) / 1000;
    if (elapsed < this.bufferTime) {
      this.buffer.delete(name);
      return true;
    }
    
    return false;
  }
}

// Usage: Jump buffering
if (inputManager.getAction('jump')) {
  inputBuffer.bufferAction('jump');
}

if (player.isGrounded() && inputBuffer.consumeAction('jump')) {
  player.jump();
}

Best Practices

Input Handling

  • Always update InputManager at the start of your game loop
  • Use axes for continuous input (movement, steering)
  • Use actions for discrete input (jump, shoot, interact)
  • Set appropriate deadzones for analog sticks (0.1-0.2)

Gamepad Support

  • Test with multiple controller types (Xbox, PlayStation, generic)
  • Provide visual prompts showing current controller type
  • Allow button remapping in settings
  • Use vibration sparingly (can be annoying)

Accessibility

  • Allow full key rebinding
  • Support multiple input methods simultaneously
  • Provide sensitivity adjustments
  • Add toggle options for hold-to-sprint/crouch
