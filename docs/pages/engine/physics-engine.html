🔬 Physics Engine

Character controllers and physics simulation

Overview

The physics engine provides character controllers and physics simulation using Rapier physics engine integration.

Key Features

  • ✅ First-person controller with camera-relative movement
  • ✅ Character controller with walk/run/crouch/jump states
  • ✅ Ground detection and slope handling
  • ✅ Stamina system
  • ✅ Player state management (vehicles, equipment)
  • ✅ Extensible stat system
  • ⏳ Rigid body physics (Rapier integration)
  • ⏳ Collision detection and response

FirstPersonController

Professional first-person controller with defined coordinate system and camera-relative movement.

Coordinate System

/**
 * COORDINATE SYSTEM:
 * - Forward (North): -Z axis
 * - Right (East): +X axis
 * - Back (South): +Z axis
 * - Left (West): -X axis
 * - Up: +Y axis
 * 
 * CAMERA:
 * - Pitch: Rotation around X axis (look up/down)
 * - Yaw: Rotation around Y axis (look left/right)
 * - Roll: Rotation around Z axis (tilt - locked)
 */

Class Definition

src/engine/player/FirstPersonController.ts
class FirstPersonController {
  private position: Vector3;
  private rotation: Euler;
  private velocity: Vector3;
  private pitch: number = 0;
  private yaw: number = 0;
  private config: FirstPersonConfig;
  
  constructor(config?: Partial) {
    this.position = new Vector3(0, 0, 0);
    this.rotation = new Euler(0, 0, 0, 'YXZ');
    this.velocity = new Vector3();
    
    this.config = {
      walkSpeed: 3.0,
      runSpeed: 6.0,
      crouchSpeed: 1.5,
      mouseSensitivity: 0.002,
      invertY: false,
      minPitch: -89,
      maxPitch: 89,
      eyeHeight: 1.6,
      crouchHeight: 0.8,
      ...config
    };
  }
  
  update(input: FirstPersonInput, deltaTime: number): void {
    this.updateRotation(input);
    this.updateMovement(input, deltaTime);
  }
  
  private updateRotation(input: FirstPersonInput): void {
    // Update yaw (left/right)
    this.yaw -= input.lookDeltaX * this.config.mouseSensitivity * 180 / Math.PI;
    
    // Update pitch (up/down)
    const pitchDelta = input.lookDeltaY * this.config.mouseSensitivity * 180 / Math.PI;
    this.pitch += this.config.invertY ? pitchDelta : -pitchDelta;
    
    // Clamp pitch
    this.pitch = Math.max(this.config.minPitch, Math.min(this.config.maxPitch, this.pitch));
    
    // Update rotation
    this.rotation.set(
      this.pitch * Math.PI / 180,
      this.yaw * Math.PI / 180,
      0,
      'YXZ'
    );
  }
  
  private updateMovement(input: FirstPersonInput, deltaTime: number): void {
    // Determine speed
    let speed = this.config.walkSpeed;
    if (input.sprint) speed = this.config.runSpeed;
    if (input.crouch) speed = this.config.crouchSpeed;
    
    // Get forward and right vectors (yaw only, ignore pitch)
    const forward = new Vector3(0, 0, -1);
    const yawQuat = new Quaternion();
    yawQuat.setFromAxisAngle(new Vector3(0, 1, 0), this.yaw * Math.PI / 180);
    forward.applyQuaternion(yawQuat);
    
    const right = new Vector3(1, 0, 0);
    right.applyQuaternion(yawQuat);
    
    // Calculate movement
    const moveDir = new Vector3();
    moveDir.addScaledVector(forward, input.moveForward);
    moveDir.addScaledVector(right, input.moveRight);
    
    if (moveDir.length() > 0) {
      moveDir.normalize();
    }
    
    this.velocity.copy(moveDir.multiplyScalar(speed));
    this.position.addScaledVector(this.velocity, deltaTime);
  }
  
  // Getters
  getCameraPosition(): Vector3 {
    return new Vector3(
      this.position.x,
      this.position.y + this.config.eyeHeight,
      this.position.z
    );
  }
  
  getCameraQuaternion(): Quaternion {
    const quat = new Quaternion();
    quat.setFromEuler(this.rotation);
    return quat;
  }
  
  getPosition(): Vector3 {
    return this.position.clone();
  }
  
  getForwardVector(): Vector3 {
    const forward = new Vector3(0, 0, -1);
    const yawQuat = new Quaternion();
    yawQuat.setFromAxisAngle(new Vector3(0, 1, 0), this.yaw * Math.PI / 180);
    forward.applyQuaternion(yawQuat);
    return forward;
  }
}

CharacterController

Advanced character controller with physics integration, multiple movement states, and ground detection.

Movement States

State Machine

  • IDLE - Standing still
  • WALKING - Normal movement
  • RUNNING - Sprint movement
  • CROUCHING - Crouched movement
  • JUMPING - In air (ascending)
  • FALLING - In air (descending)

Implementation

src/engine/physics/character/CharacterController.ts
class CharacterController {
  private stateMachine: MovementStateMachine;
  private physics: MovementPhysics;
  private groundDetector: GroundDetector;
  private slopeHandler: SlopeHandler;
  private staminaSystem: StaminaSystem;
  private config: CharacterConfig;
  
  constructor(config?: Partial) {
    this.config = {
      walkSpeed: 3.0,
      runSpeed: 6.0,
      crouchSpeed: 1.5,
      jumpForce: 5.0,
      gravity: 9.81,
      maxSlopeAngle: 45,
      stepHeight: 0.3,
      ...config
    };
    
    this.stateMachine = new MovementStateMachine();
    this.physics = new MovementPhysics(this.config);
    this.groundDetector = new GroundDetector();
    this.slopeHandler = new SlopeHandler(this.config.maxSlopeAngle);
    this.staminaSystem = new StaminaSystem();
  }
  
  update(
    input: CharacterInput,
    position: Vector3,
    cameraRotation: Quaternion,
    world: RapierWorld,
    deltaTime: number
  ): Vector3 {
    // Detect ground
    const groundInfo = this.groundDetector.detect(position, world);
    
    // Update state machine
    this.stateMachine.update(input, groundInfo.isGrounded);
    const state = this.stateMachine.getState();
    
    // Update stamina
    this.staminaSystem.update(state, deltaTime);
    
    // Calculate velocity
    const velocity = this.physics.calculateVelocity(
      input,
      cameraRotation,
      state,
      groundInfo,
      this.staminaSystem.canSprint(),
      deltaTime
    );
    
    // Handle slopes
    if (groundInfo.isGrounded && groundInfo.normal) {
      this.slopeHandler.adjustVelocity(velocity, groundInfo.normal);
    }
    
    return velocity;
  }
  
  getState(): MovementState {
    return this.stateMachine.getState();
  }
  
  getStamina(): number {
    return this.staminaSystem.getStamina();
  }
}

Ground Detection

GroundDetector

Raycasts downward to detect ground and surface normals:

src/engine/physics/character/GroundDetector.ts
class GroundDetector {
  private rayLength: number = 0.1;
  private rayOffset: number = 0.05;
  
  detect(position: Vector3, world: RapierWorld): GroundInfo {
    const rayOrigin = {
      x: position.x,
      y: position.y + this.rayOffset,
      z: position.z
    };
    
    const rayDir = { x: 0, y: -1, z: 0 };
    
    const hit = world.castRay(
      rayOrigin,
      rayDir,
      this.rayLength,
      true
    );
    
    if (hit) {
      return {
        isGrounded: true,
        distance: hit.toi,
        normal: hit.normal ? new Vector3(
          hit.normal.x,
          hit.normal.y,
          hit.normal.z
        ) : null,
        point: new Vector3(
          rayOrigin.x + rayDir.x * hit.toi,
          rayOrigin.y + rayDir.y * hit.toi,
          rayOrigin.z + rayDir.z * hit.toi
        )
      };
    }
    
    return {
      isGrounded: false,
      distance: 0,
      normal: null,
      point: null
    };
  }
}

Movement Physics

MovementPhysics

Calculates velocity based on input, state, and ground conditions:

src/engine/physics/character/MovementPhysics.ts
class MovementPhysics {
  private config: CharacterConfig;
  
  calculateVelocity(
    input: CharacterInput,
    cameraRotation: Quaternion,
    state: MovementState,
    groundInfo: GroundInfo,
    canSprint: boolean,
    deltaTime: number
  ): Vector3 {
    // Determine speed based on state
    let speed = this.getSpeedForState(state, canSprint);
    
    // Get camera forward/right (ignore pitch for ground movement)
    const forward = new Vector3(0, 0, -1);
    forward.applyQuaternion(cameraRotation);
    forward.y = 0;
    forward.normalize();
    
    const right = new Vector3(1, 0, 0);
    right.applyQuaternion(cameraRotation);
    right.y = 0;
    right.normalize();
    
    // Calculate horizontal velocity
    const velocity = new Vector3();
    velocity.addScaledVector(forward, input.moveForward * speed);
    velocity.addScaledVector(right, input.moveRight * speed);
    
    // Apply gravity if not grounded
    if (!groundInfo.isGrounded) {
      velocity.y = -this.config.gravity;
    } else {
      velocity.y = 0;
    }
    
    // Handle jump
    if (input.jump && groundInfo.isGrounded && state !== MovementState.CROUCHING) {
      velocity.y = this.config.jumpForce;
    }
    
    return velocity;
  }
  
  private getSpeedForState(state: MovementState, canSprint: boolean): number {
    switch (state) {
      case MovementState.RUNNING:
        return canSprint ? this.config.runSpeed : this.config.walkSpeed;
      case MovementState.WALKING:
        return this.config.walkSpeed;
      case MovementState.CROUCHING:
        return this.config.crouchSpeed;
      default:
        return 0;
    }
  }
}

Slope Handling

SlopeHandler

Adjusts movement velocity on slopes to prevent sliding:

src/engine/physics/character/SlopeHandler.ts
class SlopeHandler {
  private maxSlopeAngle: number;
  
  constructor(maxSlopeAngle: number = 45) {
    this.maxSlopeAngle = maxSlopeAngle;
  }
  
  adjustVelocity(velocity: Vector3, surfaceNormal: Vector3): void {
    // Calculate slope angle
    const angle = this.getSlopeAngle(surfaceNormal);
    
    // If slope is too steep, prevent movement
    if (angle > this.maxSlopeAngle) {
      velocity.x = 0;
      velocity.z = 0;
      return;
    }
    
    // Project velocity onto slope
    const right = new Vector3(1, 0, 0);
    const slopeRight = right.cross(surfaceNormal).normalize();
    const slopeForward = surfaceNormal.cross(slopeRight).normalize();
    
    const forwardSpeed = velocity.dot(new Vector3(0, 0, -1));
    const rightSpeed = velocity.dot(new Vector3(1, 0, 0));
    
    velocity.copy(slopeForward.multiplyScalar(forwardSpeed));
    velocity.addScaledVector(slopeRight, rightSpeed);
  }
  
  getSlopeAngle(normal: Vector3): number {
    const up = new Vector3(0, 1, 0);
    const dot = normal.dot(up);
    return Math.acos(dot) * 180 / Math.PI;
  }
  
  canWalkOnSlope(normal: Vector3): boolean {
    return this.getSlopeAngle(normal) <= this.maxSlopeAngle;
  }
}

Stamina System

StaminaSystem

Manages stamina for sprinting and other actions:

src/engine/physics/character/StaminaSystem.ts
class StaminaSystem {
  private stamina: number = 100;
  private maxStamina: number = 100;
  private drainRate: number = 20;      // per second while sprinting
  private regenRate: number = 15;      // per second while not sprinting
  private regenDelay: number = 1.0;    // seconds before regen starts
  private timeSinceLastDrain: number = 0;
  
  update(state: MovementState, deltaTime: number): void {
    if (state === MovementState.RUNNING) {
      // Drain stamina while sprinting
      this.stamina = Math.max(0, this.stamina - this.drainRate * deltaTime);
      this.timeSinceLastDrain = 0;
    } else {
      // Regenerate stamina
      this.timeSinceLastDrain += deltaTime;
      
      if (this.timeSinceLastDrain >= this.regenDelay) {
        this.stamina = Math.min(
          this.maxStamina,
          this.stamina + this.regenRate * deltaTime
        );
      }
    }
  }
  
  canSprint(): boolean {
    return this.stamina > 0;
  }
  
  getStamina(): number {
    return this.stamina;
  }
  
  getStaminaPercent(): number {
    return this.stamina / this.maxStamina;
  }
}

Stat System

StatSystem

Extensible stat management for health, stamina, hunger, etc.:

src/engine/stats/StatSystem.ts
class StatSystem {
  private stats: Map;
  
  constructor() {
    this.stats = new Map();
  }
  
  addStat(name: string, config: StatConfig): void {
    this.stats.set(name, new Stat(config));
  }
  
  getStat(name: string): Stat | null {
    return this.stats.get(name) || null;
  }
  
  getValue(name: string): number {
    return this.stats.get(name)?.getValue() || 0;
  }
  
  setValue(name: string, value: number): void {
    this.stats.get(name)?.setValue(value);
  }
  
  modify(name: string, amount: number): void {
    this.stats.get(name)?.modify(amount);
  }
  
  update(deltaTime: number): void {
    for (const stat of this.stats.values()) {
      stat.update(deltaTime);
    }
  }
}

class Stat {
  private value: number;
  private minValue: number;
  private maxValue: number;
  private regenRate: number;
  private drainRate: number;
  
  constructor(config: StatConfig) {
    this.value = config.initialValue;
    this.minValue = config.minValue || 0;
    this.maxValue = config.maxValue || 100;
    this.regenRate = config.regenRate || 0;
    this.drainRate = config.drainRate || 0;
  }
  
  update(deltaTime: number): void {
    // Auto-regeneration
    if (this.regenRate > 0) {
      this.modify(this.regenRate * deltaTime);
    }
    
    // Auto-drain
    if (this.drainRate > 0) {
      this.modify(-this.drainRate * deltaTime);
    }
  }
  
  modify(amount: number): void {
    this.value = Math.max(
      this.minValue,
      Math.min(this.maxValue, this.value + amount)
    );
  }
  
  getValue(): number {
    return this.value;
  }
  
  getPercent(): number {
    return (this.value - this.minValue) / (this.maxValue - this.minValue);
  }
}

Best Practices

Character Controller

  • Use FirstPersonController for simple camera-only movement
  • Use CharacterController when you need physics integration
  • Always check ground state before allowing jumps
  • Implement coyote time for better jump feel

Physics Integration

  • Use kinematic bodies for player characters
  • Lock rotation axes to prevent tipping
  • Set appropriate mass and friction values
  • Use continuous collision detection for fast-moving objects

Performance

  • Limit raycasts per frame
  • Use spatial partitioning for collision detection
  • Put sleeping bodies to sleep when stationary
  • Profile physics step time regularly
