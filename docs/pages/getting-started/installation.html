📦 Installation Guide

Set up the Space Game Engine development environment

Prerequisites

Before installing the Space Game Engine, ensure you have the following installed on your system:

Node.js & npm

  • Node.js: v18.0.0 or higher
  • npm: v9.0.0 or higher (comes with Node.js)
Check your versions:
node --version
npm --version

Download Node.js from nodejs.org

Git

Required for cloning the repository and version control.

Check Git version:
git --version

Code Editor

Recommended: Visual Studio Code with the following extensions:

  • ESLint
  • Prettier
  • TypeScript and JavaScript Language Features
  • Tailwind CSS IntelliSense

Installation Steps

1. Clone the Repository

Terminal:
git clone https://github.com/yourusername/space-game-engine.git
cd space-game-engine

2. Install Dependencies

The engine uses npm for package management. Install all required dependencies:

Terminal:
npm install
Note: This will install all dependencies including:
  • React & React DOM (v18.3+)
  • Three.js (v0.160+)
  • React Three Fiber (@react-three/fiber)
  • React Three Drei (@react-three/drei)
  • React Three Rapier (@react-three/rapier)
  • Zustand (state management)
  • TypeScript (v5.3+)
  • Vite (build tool)
  • Tailwind CSS

3. Verify Installation

Start the development server to verify everything is working:

Terminal:
npm run dev

You should see output similar to:

  VITE v5.0.0  ready in 500 ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
  ➜  press h to show help

Open your browser and navigate to http://localhost:5173/. You should see the Space Game Engine running.

Available Scripts

DEV npm run dev

Starts the development server with hot module replacement (HMR). The app will automatically reload when you make changes.

BUILD npm run build

Builds the app for production. Creates optimized bundles in the dist/ directory.

PREVIEW npm run preview

Previews the production build locally. Run this after npm run build.

LINT npm run lint

Runs ESLint to check for code quality issues.

Troubleshooting

Port Already in Use

If port 5173 is already in use, Vite will automatically try the next available port. You can also specify a custom port:

npm run dev -- --port 3000

Module Not Found Errors

If you encounter module not found errors, try:

# Clear node_modules and reinstall
rm -rf node_modules package-lock.json
npm install

# Clear Vite cache
rm -rf node_modules/.vite

TypeScript Errors

Ensure your TypeScript version is up to date:

npm install -D typescript@latest

Performance Issues

If you experience performance issues during development:

  • Close unnecessary browser tabs
  • Disable browser extensions
  • Ensure your GPU drivers are up to date
  • Try reducing the number of instanced objects in demos
