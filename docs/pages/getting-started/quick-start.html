Using the First-Person Controller

The engine includes a professional first-person controller. Let's use it!

1. Create a First-Person Scene

src/components/FirstPersonScene.tsx
import { useEffect, useRef } from 'react';
import { Canvas, useFrame, useThree } from '@react-three/fiber';
import { Sky } from '@react-three/drei';
import { FirstPersonController, FirstPersonInput } from '../engine/player';

function Player() {
  const { camera } = useThree();
  const controllerRef = useRef(new FirstPersonController({
    walkSpeed: 5.0,
    runSpeed: 8.0,
    mouseSensitivity: 0.002
  }));
  
  const keysPressed = useRef(new Set());
  const mouseDelta = useRef({ x: 0, y: 0 });
  const isLocked = useRef(false);
  
  useEffect(() => {
    const handleKeyDown = (e: KeyboardEvent) => {
      keysPressed.current.add(e.key.toLowerCase());
    };
    
    const handleKeyUp = (e: KeyboardEvent) => {
      keysPressed.current.delete(e.key.toLowerCase());
    };
    
    const handleMouseMove = (e: MouseEvent) => {
      if (isLocked.current) {
        mouseDelta.current.x += e.movementX;
        mouseDelta.current.y += e.movementY;
      }
    };
    
    const handlePointerLockChange = () => {
      isLocked.current = document.pointerLockElement !== null;
    };
    
    const handleClick = () => {
      document.body.requestPointerLock();
    };
    
    window.addEventListener('keydown', handleKeyDown);
    window.addEventListener('keyup', handleKeyUp);
    window.addEventListener('mousemove', handleMouseMove);
    document.addEventListener('pointerlockchange', handlePointerLockChange);
    document.body.addEventListener('click', handleClick);
    
    return () => {
      window.removeEventListener('keydown', handleKeyDown);
      window.removeEventListener('keyup', handleKeyUp);
      window.removeEventListener('mousemove', handleMouseMove);
      document.removeEventListener('pointerlockchange', handlePointerLockChange);
      document.body.removeEventListener('click', handleClick);
    };
  }, []);
  
  useFrame((_, delta) => {
    const input: FirstPersonInput = {
      moveForward: (keysPressed.current.has('w') ? 1 : 0) - (keysPressed.current.has('s') ? 1 : 0),
      moveRight: (keysPressed.current.has('d') ? 1 : 0) - (keysPressed.current.has('a') ? 1 : 0),
      moveUp: 0,
      lookDeltaX: mouseDelta.current.x,
      lookDeltaY: mouseDelta.current.y,
      sprint: keysPressed.current.has('shift'),
      crouch: false,
      jump: false
    };
    
    mouseDelta.current = { x: 0, y: 0 };
    
    controllerRef.current.update(input, delta);
    
    camera.position.copy(controllerRef.current.getCameraPosition());
    camera.quaternion.copy(controllerRef.current.getCameraQuaternion());
  });
  
  return null;
}

Understanding the Engine

Core Concepts

🎮 Entity Component System (ECS)

The engine uses an ECS architecture where:

  • Entities - Game objects (spacecraft, asteroids, etc.)
  • Components - Data containers (position, velocity, health)
  • Systems - Logic processors (physics, rendering, input)

🔄 Game Loop

Fixed timestep game loop with separate update and render phases:

  • Early Update - Input processing
  • Fixed Update - Physics simulation (60 Hz)
  • Update - Game logic
  • Render - Drawing to screen

🎨 Rendering

Three.js-powered rendering with React Three Fiber:

  • Materials - PBR, Standard, Unlit, Custom
  • Lighting - Ambient, Directional, Point, Spot, Area
  • Shaders - GLSL shaders for custom effects
  • Instancing - GPU instancing for 40K+ objects

🎮 Input System

Unified input handling:

  • Keyboard - Key bindings and actions
  • Gamepad - Full controller support
  • Mouse - Pointer lock and delta tracking

Creating Custom Hooks

import { useFrame } from '@react-three/fiber';
import { useRef } from 'react';

export function useRotation(speed: number = 1) {
  const rotation = useRef(0);
  
  useFrame((_, delta) => {
    rotation.current += delta * speed;
  });
  
  return rotation.current;
}

Tips and Best Practices

Performance

  • Use GPU instancing for many similar objects
  • Implement LOD (Level of Detail) for distant objects
  • Use object pooling for frequently created/destroyed objects
  • Profile with the built-in PerformanceMonitor

Code Organization

  • Keep game logic in src/game/
  • Engine code stays in src/engine/
  • UI components in src/components/ui/
  • Reusable utilities in src/utils/

TypeScript

  • Always define types for your components and systems
  • Use interfaces for public APIs
  • Leverage type inference where possible
  • Check src/types/ for existing type definitions
